## How outcomes are assigned

| Oracle label (truth, verified by a direct probe) | Outcome when the tool ... | |
|---|---|---|
| VULNERABLE | confirms it -> TP; stays silent -> FN | |
| SECURE | stays silent -> TN; confirms it -> FP | |
| POLICY_DEPENDENT / INDETERMINATE | confirms -> UNDECIDABLE_FLAGGED; silent -> UNDECIDABLE_SILENT | the truth cannot be decided from the input |
| any | returns an undetermined result -> UNDETERMINED | the tool declined to decide |
| any | refused, setup failed, skipped or unreachable -> NEEDS_INPUT | the check did not run |
| any | harness or tool crashed -> ERROR | never counted as TN |

Verdict: PASS = TP or TN; FAIL = FP, FN or ERROR; NOT DECIDED = the rest.

- **S14-admin-vuln** (POLICY_DEPENDENT; tool flagged 2/2): An admin override may be intended; the identities file cannot say 'admin may read everything', so the tool cannot tell policy from BOLA.
- **S15-share-secure** (POLICY_DEPENDENT; tool flagged 1/1): Order 1001 is explicitly shared with bob in the fixture; the tool has no way to be told about sharing.
- **S15-share-vuln** (POLICY_DEPENDENT; tool flagged 1/1): Order 1001 is explicitly shared with bob in the fixture; the tool has no way to be told about sharing.
- **S16-public** (POLICY_DEPENDENT; tool flagged 4/4): Public posts are readable by every account by design; the tool has no notion of public resources.
- **S17-same-principal** (INDETERMINATE; tool flagged 2/2): Both identities authenticate as the same account (user 42); the tool cannot know two tokens are one principal.
- **S17-ownerless** (INDETERMINATE; tool flagged 0/1): Resource 9001 has user_id=null: there is no owner to violate, and nothing says whether it should have one.
- **S22-no-id-body** (INDETERMINATE; tool flagged 0/1): The body has no resource id and no owner field, and it is identical for everyone. A template or catch-all response would look the same, so the tool cannot tell which record it is.
- **S23-owner-mismatch** (INDETERMINATE; tool flagged 0/1): The identities file declares that user 42 owns order 1001, but the record says user 7. Either the declaration or the data is wrong, and the tool cannot tell which.
- **S24-partial-status** (INDETERMINATE; tool flagged 0/1): The non-owner receives only a status value. Whether that is a security problem depends on how sensitive the status is, which the API model does not say.
